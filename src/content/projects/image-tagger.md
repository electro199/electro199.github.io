The Image Tagger is a desktop application that allows users to tag images with labels using fast keyboard shortcuts. It is built using Python, OpenCV, and PyQt, providing a user-friendly interface for efficient image labeling.

Main focus areas of the project include:

- Image labeling with keyboard shortcuts for speed and efficiency.
- Project files are saved in a JSON format, allowing for easy integration with other tools and workflows.
- The application is designed to be lightweight and fast, making it suitable for large image datasets.
- Simple and intuitive user interface, making it accessible to users of all skill levels.
